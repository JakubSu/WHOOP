WHOOP SPA OAuth Tester

This page follows the standard SPA OAuth pattern. It first calls the authenticated /api/v1/whoop/connect-url/ endpoint using your JWT, receives a WHOOP authorization URL from the backend, and then redirects the browser there. WHOOP returns to the public backend callback, and the backend redirects the browser back here when the connection is complete.

Set WHOOP_REDIRECT_URI to http://127.0.0.1:8000/api/v1/whoop/callback/ and WHOOP_FRONTEND_SUCCESS_URL to this page URL, for example http://127.0.0.1:5500/test.html?whoop=connected.
